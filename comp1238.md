* The command line is still commonly used because it can be fast, precise, and efficient for many tasks.
* Typing speed and accuracy are useful skills when working with the command line because commands must be entered correctly.

## Week 2

* **RAM** is volatile memory that temporarily stores data and programs currently being used by the computer.
* **Storage** is non-volatile and keeps files and programs even after the computer is turned off.
* My phone has **6 GB of RAM and 128 GB of storage**.
* My computer has **8 GB of RAM and 512 GB of storage**.
* To calculate the total number of pixels on a monitor, multiply its width by its height.
* A VGA resolution of **640 × 480** contains **307,200 pixels**.
* An FHD resolution of **1920 × 1080** contains **2,073,600 pixels**.
* Hexadecimal is commonly used to represent RGB colours.
* Two hexadecimal digits can represent **256 values**, from 0 to 255, which matches the range of an 8-bit RGB colour channel.
* The hexadecimal values **0xE1, 0x22, and 0xF2** convert to decimal values **225, 34, and 242**.

## Week 3

* **Markdown** is a lightweight markup language used to format text using simple symbols.
* Headings can be created using `#`, `##`, `###`, and other levels.
* Bullet lists use `-`, while numbered lists use numbers followed by a period.
* Markdown links use the format `[Lab 3](https://github.com/comp1238f26/lab3-SHADOW4AR)`.
* Markdown can be used to create links to websites such as GitHub, George Brown Polytechnic, and other resources.
* Checklists can be created using `- [ ]` for an unchecked item and `- [x]` for a completed item.
* Code blocks can be created using three backticks.
* Images can be added using Markdown image syntax.
* Emojis can be included directly in Markdown documents.
* ASCII art can be displayed inside a fenced code block.

## Week 4

* **github.dev** is a browser-based editor that can be used to edit files directly from a GitHub repository.
* GitHub repositories can be edited without installing a separate code editor by using the browser-based development environment.
* Common keyboard shortcuts include **Ctrl-C** for copy, **Ctrl-V** for paste, and **Ctrl-Z** for undo.
* **Ctrl-A** selects all text and **Ctrl-F** searches for text within a file.
* **Ctrl-Shift-V** can be used to open the Markdown preview in the editor.
* Search tools can be used to find specific text quickly inside files.
* Regular expressions can be used to search for patterns rather than only exact text.
* `line\d` can match the word `line` followed by one digit.
* `line\d+` can match `line` followed by one or more digits.
* `line\d*` can match `line` followed by zero or more digits.
* `^line` searches for `line` at the beginning of a line.
* `line$` searches for `line` at the end of a line.
