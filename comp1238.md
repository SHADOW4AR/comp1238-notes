# COMP1238 Notes

## Week 1

* Typing speed and accuracy are important command-line skills. My Lab 1 typing test result was **68.3 WPM** with **97.56% accuracy**, 82 characters, and 2 errors.
* Command-line skills are useful because commands can often be faster and more precise than using graphical interfaces.
* Accuracy is important when working in the terminal because a small typing mistake can cause a command to fail or affect the wrong file.

## Week 2

* Computer memory and storage are different. **RAM** is temporary and volatile memory used while programs are running, while **storage** is non-volatile and keeps files and programs after the computer is turned off.
* A monitor's total number of pixels can be calculated by multiplying its width by its height. For example, **640 × 480 = 307,200 pixels**, while **1920 × 1080 = 2,073,600 pixels**.
* Hexadecimal is commonly used for RGB colours. Two hexadecimal digits can represent **256 values from 0 to 255**, which matches the range of an 8-bit RGB colour channel.
* Hexadecimal values can be converted to decimal. For example, **0xE1 = 225**, **0x22 = 34**, and **0xF2 = 242**.

## Week 3

* Markdown uses simple symbols to format text, including `#` for headings, `-` for bullet lists, and numbered lists for ordered information.
* Markdown links use the format `[link text](URL)`.
* Markdown can contain headings, links, images, checklists, emojis, code blocks, and other formatted content.
* ASCII art can be displayed inside a fenced code block using three backticks.

## Week 4

* GitHub's `github.dev` editor can be opened directly from a repository and provides a browser-based development environment for editing files.
* Useful keyboard shortcuts include **Ctrl-C** for copy, **Ctrl-V** for paste, and **Ctrl-Z** for undo.
* Other useful shortcuts include **Ctrl-A** for select all, **Ctrl-F** for find, and **Ctrl-Shift-V** for opening the Markdown preview.
* Regular expressions can be used to search for patterns. Examples practiced in Lab 4 included `line\d`, `line\d+`, `line\d*`, `^line`, and `line$`.

## Week 5

* The Bandit game provides practice with Linux command-line navigation, file handling, and discovering passwords stored in files.
* The `cat` command can be used to display the contents of a file.
* Special filenames can require different command syntax. For example, a filename beginning with `-` can be read using `cat < -`, and filenames containing spaces can be referenced with quotation marks.
* Hidden files can be discovered and accessed from the command line, which is useful when information is not visible in a normal directory listing.
